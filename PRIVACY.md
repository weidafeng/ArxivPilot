# Privacy Policy for ArxivPilot

**Last updated: 2026-04-06**

## Overview

ArxivPilot is a Chrome extension that opens reading-assistance tabs for arXiv papers. This policy describes how the extension handles user data.

## Data Collection

ArxivPilot **does not collect, store, or transmit any user data**. Specifically:

- No personal information is collected
- No browsing history is recorded
- No usage analytics are gathered
- No data is sent to any external server

## Permissions Usage

| Permission | Purpose |
|---|---|
| `tabs` | Read the current tab's URL to detect the arXiv paper ID; open new tabs for reading tools |
| `tabGroups` | Group the arXiv tab and reading-assistance tabs together under the paper ID |
| `contextMenus` | Add a right-click menu entry on arXiv pages for quick access |
| `host_permissions (arxiv.org)` | Detect arXiv paper IDs from abs/pdf/html page URLs |

## Third-Party Services

When you use ArxivPilot, it opens tabs to the following third-party websites based on your action:

- [hjfy.top](https://hjfy.top) — translation service
- [papers.cool](https://papers.cool) — KIMI AI paper summary
- [alphaxiv.org](https://alphaxiv.org) — paper overview

These sites have their own privacy policies. ArxivPilot does not share any data with them beyond the arXiv paper ID included in the URL.
